AI YouTube Factory

A private production tool for one YouTube channel.

AI YouTube Factory is an internal tool that its developer uses to produce original animated short stories and to upload them to the developer's own YouTube channel. It is not offered to the public and has no user sign-up.

What it does with YouTube

  • Uploads the developer's own finished videos to the developer's own channel (initially as private).
  • Reads the channel's basic information and the status of uploaded videos.
  • Reads YouTube Analytics for those videos to decide which stories to make next.

It uses YouTube API Services. By using it you agree to the YouTube Terms of Service.
